# MedLink / doctors_check

## Руководство администратора

MedLink — интерфейс для управления учетными записями сотрудников медицинской платформы.

### Возможности

- просмотр общего числа пользователей, активных, ожидающих активации и заблокированных учетных записей;
- поиск по имени и рабочему email;
- фильтрация по роли и статусу;
- добавление пользователя с ролями **Врач**, **Администратор** или **Регистратура**;
- выбор пользователей для групповых действий;
- экспорт списка учетных записей в CSV;
- сохранение добавленных пользователей в `localStorage` браузера.

### Добавление пользователя

1. Нажмите **Добавить пользователя**.
2. Укажите имя и фамилию сотрудника.
3. Введите рабочий email.
4. Выберите роль.
5. Нажмите **Создать пользователя**.

Новая запись появится в начале списка со статусом **Ожидает активации**. В прототипе приглашение только имитируется уведомлением.

### Поиск и фильтры

Введите часть имени или email в строку поиска. Для уточнения списка выберите роль и статус. Кнопка **Сбросить** возвращает все фильтры к исходному состоянию.

### Экспорт

Кнопка **Экспорт CSV** скачивает файл `medlink-users.csv` с именем, email, ролью, статусом и временем последнего входа всех пользователей.

## Запуск проекта

Это статическое приложение без сборки и внешних зависимостей. Запустите локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

После запуска откройте в браузере http://localhost:8000.

## Технологические ограничения

- авторизация и разграничение прав пока не подключены к серверу;
- данные хранятся только в `localStorage` текущего браузера;
- действия меню строки и пагинация представлены интерфейсом-заготовкой;
- email-приглашения, аудит действий и API отсутствуют.

Не используйте прототип с реальными медицинскими или персональными данными без серверной авторизации, шифрования, аудита и соответствия требованиям к защите медицинской информации.
